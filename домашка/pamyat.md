# Память

## HDD и SSD

| Параметр | HDD | SSD |
|---|---|---|
| Принцип работы | Данные лежат на магнитных пластинах. Головка перемещается и читает или пишет, пока пластины крутятся | Данные лежат в микросхемах флеш-памяти NAND. Контроллер сразу обращается к нужным ячейкам |
| Скорость чтения/записи (примерно) | Обычный диск 7200 об/мин: около 120-200 МБ/с | SATA: до 550 МБ/с. NVMe: примерно 3000-7000 МБ/с |
| Наличие движущихся частей | Есть: пластины и головки | Нет |
| Устойчивость к ударам | Низкая. Удар во время работы может повредить пластины или головки | Высокая. Механики нет, удары переносит лучше |
| Уровень шума | Слышно вращение и движение головок | Почти бесшумный |
| Цена за 1 ТБ | Дешевле. Примерно 2-4 тыс. руб. | Дороже. Примерно 6-12 тыс. руб., зависит от SATA или NVMe |
| Срок службы / ограничения | Ограничен механикой. Обычно несколько лет. Боится падений, вибрации и перегрева | Ограничен износом ячеек при записи (ресурс TBW). Для обычной работы хватает на годы. Чтение ячейки почти не изнашивает |
| Пример использования | Архив, фильмы, резервные копии, большие объемы, где скорость не главное | Система, программы, игры, ноутбук |

Цены и скорости приблизительные: у конкретной модели они отличаются.

## Термины

**DDR** - Double Data Rate, двойная скорость передачи данных. Это оперативная память SDRAM, у которой данные передаются два раза за один такт: по переднему и по заднему фронту сигнала. Поэтому за тот же такт проходит вдвое больше данных, чем у памяти с одной передачей за такт. Поколения: DDR, DDR2, DDR3, DDR4, DDR5. Между собой они не совместимы.

**DIMM** - Dual In-line Memory Module, модуль памяти с двумя рядами контактов. Это сама планка оперативной памяти, которая ставится в слот материнской платы. Контакты с двух сторон независимые. Для ноутбуков используют укороченный модуль SO-DIMM.

**Ранг (rank)** - группа микросхем на модуле, с которой контроллер памяти работает как с одним блоком шириной 64 бита (72 бита, если есть ECC). У single-rank одна такая группа, у dual-rank две. Ранг не равен стороне планки: чипы ранга могут стоять и с одной стороны, и с двух.

**CAS Latency (CL)** - задержка CAS, Column Address Strobe. Это число тактов от команды «прочитать столбец» до момента, когда первые данные появляются на шине. При одной и той же частоте меньший CL дает меньшую задержку. У памяти с разной частотой такты разной длины, поэтому CL сравнивают через время в наносекундах, а не только по числу.

**Тайминги** - набор задержек памяти в тактах. Обычно их пишут через дефис, например 16-18-18-36. Это CL, tRCD, tRP и tRAS.

- CL - задержка выдачи данных после выбора столбца
- tRCD - пауза между открытием строки и обращением к столбцу
- tRP - время закрыть текущую строку перед открытием другой
- tRAS - сколько минимум строка должна оставаться открытой

**Двухканальный режим** - контроллер работает сразу с двумя модулями по двум каналам. Шина становится 128 бит вместо 64, пропускная способность примерно удваивается. Для этого ставят две одинаковые планки в парные слоты, которые на плате обычно отмечены одним цветом. Одна планка того же объема работает только в одноканальном режиме и медленнее отдает данные процессору.
